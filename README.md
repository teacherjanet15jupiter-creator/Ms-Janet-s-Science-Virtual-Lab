# 🔬 SciQuest P6 – Primary 6 Science Virtual Lab Arena

**SciQuest P6** is an interactive digital Science learning platform designed for Primary 6 students at Bina Bangsa School.

It combines virtual laboratories, quizzes, curriculum-linked revision tools, augmented reality experiences, and **Dr. Atom**, an AI Science mentor powered by Google Gemini.

The platform supports inquiry-based learning, scientific reasoning, revision, and independent exploration while complementing the **Cambridge Primary Science** curriculum.

🌐 **Live App:**  
https://sciquest-p6-primary-6-science-lab-arena.ai.studio

---

## 🌟 Purpose

SciQuest P6 aims to help students:

- explore Science concepts through interactive simulations
- strengthen understanding of Primary 6 Science topics
- practise scientific reasoning and process skills
- connect classroom learning with real-world applications
- develop confidence in answering Science questions
- learn through experimentation, investigation, and discovery
- revise key concepts in an engaging digital environment

The platform is designed especially for upper-primary learners and can be used during lessons, revision periods, e-learning, enrichment, or independent study.

---

## 🧪 Main Features

### 🔬 Virtual Science Labs

Students can explore interactive Science activities related to topics such as:

- Energy and energy conversions
- Forces and friction
- Plant transport systems
- Ecosystems, food chains, and food webs
- Electrical circuits
- Earth, Moon, and space concepts

The virtual labs allow students to observe relationships, test variables, and explore scientific ideas in a visual way.

### 🤖 Dr. Atom – AI Science Mentor

Dr. Atom is the built-in AI Science mentor.

Students can ask Science questions and receive explanations designed for Primary 6 learners.

Dr. Atom supports:

- Science concept explanations
- structured open-ended answers
- Cambridge-style scientific vocabulary
- exam tips
- revision support
- voice input
- text-to-speech
- optional search-grounded answers

Dr. Atom encourages students to explain ideas using scientific cause-and-effect reasoning.

## 🔐 API Key and Security

The Gemini API key is handled on the server side.

The application uses:

```env
GEMINI_API_KEY
```

The actual API key should never be committed to GitHub.

Only the example environment file is included:

```text
.env.example
```

Real environment files are excluded using `.gitignore`.

---

## ⚙️ Environment Setup

Create a local `.env` file and add:

```env
GEMINI_API_KEY=your_api_key_here
APP_URL=your_application_url
```

Do not upload your real `.env` file or API keys to GitHub.

---

## 🚀 Running the Project Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application runs through the Express server with Vite development middleware.
